우아한테크코스 3주 차 프리코스 "로또"

---

## 1. 애플리케이션 실행 및 입력 유효성 검증

사용자로부터 로또 구입 금액, 당첨 번호, 보너스 번호를 입력받고 모든 값의 유효성을 검증한다.

### 1-1. 로또 구입 금액 입력 및 유효성 검사

- 입력 형식: 로또 구입 금액을 숫자로 입력받는다.

- 유효성 조건:

    - 구입 금액은 1,000원 단위여야 한다. (1,000으로 나누어 떨어지지 않으면 예외 발생)

    - 입력값이 숫자가 아니거나, 빈 문자열(null) 이거나 0 이하이면 예외 발생

    - 입력 문자열에 공백이 포함된 경우, 공백을 제거한 후에도 숫자가 아니면 예외 발생

### 1-2. 당첨 번호 입력 및 유효성 검사

- 입력 형식: 당첨 번호 6개를 쉼표(,)로 구분하여 입력받는다.

- 유효성 조건:

   - 입력된 숫자는 총 6개여야 한다.

   - 각 숫자는 1 이상 45 이하의 정수여야 한다.

   - 중복된 번호가 존재하면 예외 발생

### 1-3. 보너스 번호 입력 및 유효성 검사

- 입력 형식: 보너스 번호는 단일 숫자로 입력받는다.

- 유효성 조건:

   - 번호는 1 이상 45 이하의 정수여야 한다.

   - 당첨 번호 6개와 중복될 수 없다.

   - 숫자가 아니거나, 범위를 벗어나거나, 중복된 경우 예외 발생

---

## 2. 로또 발행 및 당첨 로직

입력된 구입 금액에 맞춰 로또를 발행하고, 각 로또의 당첨 여부를 계산한다.

### 2-1. 로또 발행 개수 계산

- 구입 금액을 1,000원으로 나누어 발행 개수(n)를 계산한다.

### 2-2. 로또 번호 생성

- 각 로또는 1부터 45 사이의 중복되지 않은 정수 6개로 구성된다.

- 무작위 숫자 추출 시 MissionUtils.Random.pickUniqueNumbersInRange(1, 45, 6)을 사용한다.

### 2-3. 번호 정렬

- 생성된 각 로또 번호는 오름차순으로 정렬되어야 한다.

### 2-4. 당첨 결과 계산

- 사용자가 구매한 각 로또에 대해 당첨 번호 6개 및 보너스 번호 일치 여부를 비교한다.

- 아래 기준에 따라 당첨 등수 및 금액을 결정한다.

| 등수 | 조건 | 상금 |
|------|------|------|
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |


---

## 3. 결과 출력 및 수익률 계산

### 3-1. 로또 발행 내역 출력

- 총 구매한 로또 개수를 출력한다.

- 각 로또 번호를 [숫자, 숫자, 숫자, 숫자, 숫자, 숫자] 형태로 출력한다.

### 3-2. 당첨 통계 출력

- 등수별 일치 개수, 당첨 금액, 개수를 출력한다.

### 3-3. 수익률 계산 및 출력

- 총 당첨 금액 / 구입 금액 × 100 으로 수익률을 계산한다.

- 소수점 둘째 자리에서 반올림하여 출력한다.

---

## 4. 오류 및 예외 처리
### 4-1. 공통 규칙

- 잘못된 입력이 들어오면 즉시 Error를 발생시키고 프로그램을 종료한다.

- 모든 에러 메시지는 반드시 [ERROR] 로 시작해야 한다.

### 4-2. 구체적 오류 조건

- 구입 금액이 숫자가 아니거나 1,000원 단위가 아닌 경우

- 구입 금액이 0 이하인 경우

- 당첨 번호가 6개가 아닌 경우

- 당첨 번호 중 중복된 숫자가 존재하는 경우

- 보너스 번호가 당첨 번호와 중복되는 경우

- 번호가 1~45 범위를 벗어나는 경우

- 공백, 빈 문자열, null 입력 등 잘못된 형식의 입력
